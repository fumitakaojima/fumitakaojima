# 尾島 史隆

AIを活用した業務設計、社内BIの要件定義、新市場の検証に取り組んできました。

課題を整理し、試作や調査・データをもとに方針を考え、関係者と実行してきました。現在はプロダクトマネージャーへの転向を目指しています。

## 取り組んだ3つの仕事

### 01｜人とAIの役割分担を設計

Cursor上のClaude Codeを使い、記事制作から社内CMSへの公開まで進める「自律実行」と、人の判断を段階的に組み込む「コーチング」の2つのワークフローを設計・実務導入しました。

### 02｜数字を意思決定につなぐ

社内BIの要求整理・要件定義・画面試作を担当。必要な指標や表示を整理し、エンジニアと仕様をすり合わせました。

### 03｜事業の前提を検証し直す

市場調査・ユーザーインタビュー・KPI／KGIの検証を通じて、当初の事業方針を再検討。上長へ撤退・他領域への転換を提案しました。
