# Fumitaka Ojima｜尾島 史隆

**新しいものを考え、専門性の異なる人たちと形にする。**

Webメディア事業で、新しい領域の立ち上げやAIを活用した仕組みづくりに取り組んできました。

現在は、ユーザーの課題から「何を、なぜつくるか」を考え、チームで実現するPdMを目指しています。

## 3つの仕事と、そこでの判断

### 01｜AIに任せること、人が考えること

記事制作では、スピードを重視する場面と、課題や方針を深く考える場面がありました。

そこで、Cursor上のClaude Codeを使い、「自律実行」と「コーチング」の2つのワークフローを設計・実務導入しました。

両方とも人が途中で介入でき、目的によってAIが人に判断を求めるタイミングを変えています。

### 02｜数字を、次の判断につなげる

社内BIの要件定義と画面試作を担当しました。

必要な指標や画面構成を整理し、エンジニアと仕様を具体化。数字を集めるだけではなく、状況を把握し、次の判断につなげるための画面を考えました。

### 03｜施策がうまくいっても、事業は成立するのか

一部の獲得指標が目標を達成している一方で、事業全体の成果は伸び悩んでいました。

市場調査・ユーザーインタビュー・KPI分析を通じて当初の前提を再検討し、上長へ事業方針の見直しを提案しました。
